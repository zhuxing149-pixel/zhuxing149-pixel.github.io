# 工资个税核算 · 到手工资核对

按月计算**累计预扣预缴个税**与**税后到手工资**，并与公司工资条逐项比对，标出异常。

> 🔒 **隐私声明（请先读）**
>
> 本工具是**纯静态网页**，**完全在你自己的浏览器里运行**：
> - 不连接任何服务器，不上传任何数据，没有账号、没有后台、没有数据库；
> - 你的工资信息**只保存在你自己这台设备的浏览器本地**（localStorage），别人无法看到；
> - 代码完全透明，你可以随时用浏览器「查看源代码」确认没有任何网络上传。
>
> **数据会丢的两种情况**：清除浏览器数据 / 使用无痕窗口 / 更换浏览器或设备时，本地存档会丢失。
> 请养成习惯：需要备份时，用「导入导出」里的 **导出 Excel** 存一份；换设备时，用 **导入 Excel** 恢复。

## 计算口径

> 界面上**不展示**下列公式（按需求刻意隐藏），仅在此文档留档备查。

```
请假扣发   = 请假时数 ÷ 标准计薪时数 × (基本工资 + 绩效奖 + 电话津贴)
个人社保   = (基本工资 + 绩效奖) × 社保折算比例 × 社保综合缴纳比例
个人公积金 = (基本工资 + 绩效奖) × 公积金个人缴纳比例

应发合计   = 基本工资 + 住宿补贴 + 绩效奖 + 电话津贴 + 其他（税前） − 漏打卡 − 请假扣发
当月收入   = 应发合计
累计应纳税所得额 = 累计收入 − 5000×月序 − 累计社保公积金 − 累计专项附加扣除
本月个税   = 累计应纳税所得额 × 预扣率 − 速算扣除数 − 上月累计已缴税额
            （结果为负时暂不退税，按 0 计，年度汇算多退少补）
扣发合计   = 个人社保 + 个人公积金 + 本月个税 + 水电费 + 房租 + 其他扣发
实发合计   = 应发合计 − 扣发合计
本次发放   = 实发合计 − 前期已发
```

- **月序**按**工资发放月**在该自然年内的序号计（1~12），跨年重新累计。
- 另附**旧算法**（月度七级税率表）参考值，便于判断税负跳档是否合理。
- 专项附加扣除按月填一个总额（不细分项目）。

### ⚠️ 一个容易搞错的地方

`当月收入 = 应发合计`，**不再单独减一次请假扣发**。请假扣发已经含在应发合计里，若两边都减会被扣两次，全年累计收入少算、个税算低、异常被掩盖。

### 三个派生字段（请假扣发 / 个人社保 / 个人公积金）

每个字段标题行右端有一个**模式胶囊**，显示当前模式，点它即可切换：

- **默认「自动」**：输入框浅蓝底、只读，值**永远实时等于公式结果**。
- **点一下变「手动」**：浅黄底加粗、可编辑，你填的值参与计算，异常区提示「手动填写 ¥X，公式结果 ¥Y」。
- **再点一下回「自动」**：立刻用公式值覆盖手填值。
- 每次切换提示「已调整为手动模式 / 已调整为自动模式」。

**模式只由点击决定**，不根据数值差异自动推断。模式**不存档**（手动是"本次编辑有效"的临时覆盖）。

比例字段按**百分数**录入（填 `10.5` 表示 10.5%），导出 Excel 也按百分数写出，导入时自动还原。

## 功能

- **月度核算**：所属月 / 发放月双月份选择，三个分区（收入项 / 税前扣除 / 税后扣除）实时计算应发合计、个税、到手金额。
- **工资条比对**：选填公司工资条上的应发 / 扣税 / 实发，自动比对差额并标异常。
- **异常检测**：扣税不一致、实发不一致、应发为 0/负数、请假扣发超限、漏填标准计薪时数、跨年缺月份、手动覆盖提示等。
- **存档**：滚动保存 24 个月（两年），超出自动覆盖最早月份并提示；明细页支持勾选批量删除（删除前二次确认）。
- **导入导出**：按月 / 按年（不满一年导出当年全部）/ 全部；导出与导入**同一套 Excel 模板**，无需二次处理；含 4 个工作表（工资数据 / 沿用设置 / 年度起算基数 / 填写说明）。
- **设置**：字段沿用上月（逐字段勾选）、年度累计起算基数（年中开始记录时补录）、清空全部数据。

## 测试

```bash
npm install            # 仅测试需要（jsdom 等开发依赖）
npm test               # 全部：算法回归 + Excel 往返 + 页面冒烟
node test/regression.js        # 算法回归（106 项）
node test/excel-roundtrip.js   # 浏览器端 Excel 导出→导入往返（25 项）
node test/ui-smoke.js          # 纯静态页面运行时冒烟（132 项）
```

- `regression.js`：用真实工资样本逐月比对个税与到手金额，覆盖跨年重置、负税额归零、四舍五入边界、三个派生公式、口径等价性。
- `excel-roundtrip.js`：验证导出→导入往返字段值、百分比列、沿用设置、年度基数、备注全部一致。
- `ui-smoke.js`：jsdom 加载页面执行前端脚本，校验字段分区、模式胶囊、手动/自动切换、改输入不误判、批量删除确认、界面不含计算公式等。
